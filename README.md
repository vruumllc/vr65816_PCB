# vr65816
WDC 65C816 Single Board Computer compatible with Rumbledethump's Picocomputer Architecture

## Goals
- Use 2 RasberryPi Pico2s with Rumbledethumps' rp6502 firmware
- Run WDC 65C816 at up to 8Mhz, clocked by Pico2W RIA
- Use currently produced through-hole ICs only, and no programmable logic
- Use 1MB SRAM, 64kB extended RAM, and no hardware ROM
- Use WDC 65C22 for timers and peripheral I/O
- Use KiCad to create fully open source schematic and board source files
- Run all existing apps and games ("ROMs") for the Rumbledethumps' RP6502 Picocomputer
- Enable creation of new "ROMs" utilizing advanced features and memory of the '816
