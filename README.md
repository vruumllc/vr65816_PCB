# vr65816
WDC 65C816 Single Board Computer compatible with Rumbledethump's Picocomputer Architecture

## Goals

- Uses 2 RasberryPi Pico2s with Rumbledethumps' rp6502 firmware
- Runs WDC 65C816 at up to 8Mhz, clocked by Pico2W RIA
- Uses currently produced through-hole ICs only, and no programmable logic
- Features 1MB RAM, 64KB extended RAM, and no hardware ROM
- Features WDC 65C22 for timers and peripheral I/O
- Runs all existing apps and games ("ROMs") for the Rumbledethumps' RP6502 Picocomputer
- Enables creation of new apps and games ("ROMs") utilizing advanced features and memory of the '816
